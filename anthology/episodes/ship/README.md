# Before the Doors Open

Original fictional Ship-It Ginger Ale episode, thematically extending workbook Q3's named ownership under pressure. It is not a direct workbook adaptation or a correct-answer mapping.

A harmless paper-city exhibit double-counts visitors. The lead establishes disclosure before choosing a live demonstration with resets or a clearly labelled recorded rehearsal. Both branches allocate responsibilities. Live participation costs throughput and certainty; playback costs agency and real-use observation.

## Play and build

`python anthology/episodes/ship/build.py` builds the standalone `anthology/dist/ship.html`. `node anthology/episodes/ship/test-doors.cjs` tests both outcomes, one untimed decision, pause/resume, invalid/duplicate input, replay, completion, session messages, raster/fallback controller and geometry.

Protocol: `anthology-v1`; id `ship`; outcomes `live`, `rehearsal`. No registry or hub mutation in this isolated episode.

37 seconds setup; 36 seconds live consequence or 29 seconds rehearsal consequence. The choice holds indefinitely. Every essential line is captioned with speaker attribution. Native keyboard buttons, visible focus, reduced motion and pause are available. Generated stills use camera reframing and dissolves, not character animation or generated video. No natural dialogue audio is included. Original SVG remains an editable offline fallback.

## Verification boundaries

Node source/state/controller tests are not browser rendering tests. Browser review was not performed because the current browser route had an access-policy denial. No alternate route was used. Art dimensions and hotspot bounds are checked separately before integration.
