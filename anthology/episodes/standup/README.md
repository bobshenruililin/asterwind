# The Quiet Minute

Original fictional Standup Seltzer episode, thematically linked to the source workbook's Q8, not a verbatim adaptation. Design participation rather than simply demand confidence. Both speaking turns and written contributions have benefits and costs.

A 37-second setup plays automatically, followed by exactly one untimed choice: turn the table or pass the slips. The chosen consequence lasts about 29 seconds. Both endings leave honest unfinished work. No scores, forced moral verdict, or claim that an agenda was sent in advance.

This is a captioned illustrated animatic with authored camera/prop motion, not completed character animation or recorded voices. Generated plates replace the vector fallback when all four load; failed/slow art loading retains a playable fallback. Human performance and visual browser QA remain pending. Existing browser restrictions were not bypassed.

Run `python anthology/episodes/standup/build.py` for self-contained `anthology/dist/standup.html`. Run `node anthology/episodes/standup/test-quiet.cjs` for state and geometry checks. Add to registry as id `standup`, adapter `anthology-v1`, outcomes `round` and `slips`; parent integrator owns shared registry/hub updates.
