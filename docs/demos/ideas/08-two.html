← Ideas8 · Two players, one call
The idea. Built for a CCGL seminar: two people share one device and each decides in secret, so neither anchors on the other. The reveal shows what each choice keeps and costs, then the game gives you a task. If you disagree, argue for the other person’s choice; if you agree, find the cost you both skipped. The learning is the conversation, and the game only sets it up. It uses the six stories’ own scripts, unchanged.
