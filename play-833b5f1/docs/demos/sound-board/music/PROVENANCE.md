# Music provenance

- `seam-night-sketch.mp3`, `seam-dawn-sketch.mp3`: original sketches composed in code for this project by Opus (`../compose.py`; the `.mid` files are the scores). Rendered with FluidSynth 2 and the FluidR3 GM SoundFont (Frank Wen, MIT licence; Debian package `fluid-soundfont-gm`). Not heard by ear: measured only (peak −5.7 / −6.5 dBFS, no clipping).
- `km-*-excerpt.mp3`: 45-second excerpts, trimmed and faded (changes made), of tracks by Kevin MacLeod (incompetech.com), licensed under Creative Commons: By Attribution 4.0 (creativecommons.org/licenses/by/4.0). Titles: "Gymnopedie No 1", "Dreamy Flashback", "Wholesome", "Carefree". Credit is required wherever they are used.
