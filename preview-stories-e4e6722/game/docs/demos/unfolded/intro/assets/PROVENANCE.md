# Campus opening concept art

Created 6 November 2026 with the built-in image generation tool for this project. These are fictional paper-miniature locations, not photographs or verified depictions of CCGL or any real campus. Real location photographs have not yet been supplied. No studio logo is reproduced.

- `classroom-concept-v1.webp`: a late class, blank blackboard, foreground notebook, departing adult paper silhouettes.
- `notebook-concept-v1.webp`: a blank notebook on the same kind of desk, generated with the classroom as a continuity reference.
- `courtyard-concept-v1.webp`: a rain-wet covered campus walk toward an amber doorway, generated with the classroom as a material and palette reference.

All three are 1672 × 941 pixels. WebP files are compressed format derivatives of the original generated PNGs. The generated plates were inspected as images; that inspection does not establish final browser framing or animation quality. Text is not burned into these images: the title and course label are editable HTML.

The existing Asterwind corridor and The Quiet Minute master plate were inspected for visual continuity. The final opening reveals the existing live dispenser rather than generating a competing machine.

The generation tool did not expose a model version, seed, or cost. No external paid media provider, new account, or subscription was used. No new license is assigned to project artwork by this file. Existing project rights and attribution remain unchanged.
