# Corridor dispenser · Figure prototype

One theatrical drink opens one story. A paper cabinet turns between its labelled front and an optional cutaway. The machine is the navigation, not a separate menu. This is a crafted 2.5D SVG study, not a free-orbit 3D object. No real purchase.

Parts: floor, shadow, two feet, bottom fold, front shell, side shell, top fold, six folded edge strips, sign back, sign face, four sign fasteners, display recess, four window rails, window inner shadow, five can bodies, five lids, five base rims, five paper labels, five pull tabs, five selection trays, five availability strips, pickup recess, pickup flap, two hinges, service door, two internal rails, five coil shelves, five shelf supports, delivery chute, motor housing, drive wheel, four mounting fasteners, handle and two handle mounts. Flat paper decoration is intentionally not represented as physically interlocking pipe geometry.

Anatomy principles: solid depth, front-to-back painter order, purposeful part detail, moving subject, one clear physical object. User instructions override the skill's surrounding figure card, readouts and secondary labels. Controls are semantic HTML, visually registered to the illustrated cabinet. No shader, external font, framework or CDN dependency.

Only The Seam is playable. Four other drinks are pitches, clearly marked IN DEVELOPMENT. No new scenario content is represented as complete. The Seam remains untouched and standalone. This hub embeds its existing runtime and adds a return control outside it. No branch outcome is exposed in the hub.
