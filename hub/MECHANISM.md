# Six folds, one table

Optional anthology coda, not an assessed-route requirement. Turn the cabinet to find six paper connectors. Each is held shut until its episode reaches a real ending. Either outcome releases the same part; no moral score or preferred answer. Rotate released connectors until their arrow/notch points upward, joining the vertical channel. The latch opens only when all six are aligned. It unfolds a small SVG paper worktable with six differently coloured chairs. Refold closes it without discarding progress.

This is a simple tactile alignment puzzle, not a complex escape-room challenge or a completed cinematic reward. It is an optional invitation to connect the stories rather than a test of leadership correctness. It does not alter, gate or interrupt any story.

Completion is read from the existing validated progression record. New episodes require matching live frame/session and an allowed terminal outcome; original Seam uses the actual terminal-state adapter. The mechanism's separate local save only remembers rotations/open state. It cannot release a fold without a matching completion record. Storage denial falls back to memory. Local saves are convenience, not secure assessment evidence.

The table is code-native SVG, not generated art. Actual browser layout, touch, screen-reader and visual feel remain unverified under the current browser restriction. Keyboard buttons, explicit labels, focus return, reduced-motion styles and 44px minimum controls are implemented and source-tested. State/controller tests are in test-mechanism.cjs.

## Short assessed route recommendation

Keep the full six-story anthology available for exploration, but do not promise it fits five minutes. Current automatic film footage across all six is approximately 7m40–8m04 before decision pauses, navigation or discussion. A separate two-episode assessed demonstration is more suitable: The Quiet Minute (participation and interpretation), then The Missing Name (credit and agency). Allow the audience to choose, see one consequence each, then discuss what each approach protected and what it cost. No route is automatically forced; this is a presentation recommendation, not additional game UI. The six-fold coda is optional after-class exploration and should not consume the short assessment slot.
